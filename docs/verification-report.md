`PASS` 表示执行且符合本项预期；`FAIL` 表示执行但不符合；`BLOCKED` 表示明确条件阻止执行；`NOT_RUN` 表示尚未执行。执行失败后保留原记录并补充修复和重测结果，不把计划命令冒充执行证据。
